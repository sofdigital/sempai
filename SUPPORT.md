# Support Guidelines

## Getting Help

If you need assistance with this project, please use the following support channels:

- **Issues:** For bug reports, feature requests, or general questions, open an issue in the [Issues](./issues) tab.
- **Email:** For private or sensitive matters, contact [support@sofdigital](mailto:support@sofdigital.net).

## Before Requesting Support

- Review the [README.md](./README.md) for setup and usage instructions.
- Check the [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md), [LICENSE](./LICENSE), and [SECURITY.md](./SECURITY.md) for policies and guidelines.
- Search existing issues to see if your question or problem has already been addressed.

## Supported Versions

This project targets .NET 9. Support is provided for the latest release only.

## Response Times

We aim to respond to support requests within 3 business days.

## Professional Support

For enterprise or commercial support agreements, please contact support@sofdigital.

## Contribution

If you wish to contribute fixes or improvements, please review the [CONTRIBUTING.md](./CONTRIBUTING.md) guidelines (if available) before submitting a pull request.

Thank you for using and supporting this project!
